\# countCyclesCPU — Анализатор стоимости вычисления выражений



\## О проекте

Данная программа предназначена для лексического, синтаксического и семантического анализа математических и логических выражений, записанных в обратной польской записи (ОПЗ). 



Программа строит абстрактное синтаксическое дерево (AST), проверяет корректность типов (включая сужающие преобразования) и вычисляет суммарную стоимость выполнения выражения в тактах процессора.



\## Основной функционал

\- \*\*Парсинг ОПЗ:\*\* Построение синтаксического дерева из выражений в обратной польской записи.

\- \*\*Поддержка типов:\*\* Работа с широким спектром типов данных (от `bool` до `double`).

\- \*\*Семантическая валидация:\*\* Строгая проверка недопустимых операций (например, `%` для `float`), сужающих преобразований и лимитов стоимости.

\- \*\*Кастомные веса:\*\* Поддержка пользовательских весов операций через внешний конфигурационный файл.

\- \*\*Визуализация:\*\* Генерация визуального представления синтаксического дерева в формате DOT.

\- \*\*Fail-Fast архитектура:\*\* Мгновенная остановка парсинга при обнаружении критических синтаксических ошибок для предотвращения каскадных сбоев.



\## Структура проекта

\- `src/` — исходный код программы (модели, парсеры, утилиты, ввод/вывод).

\- `tests/` — набор из 51 Black-Box теста, покрывающих все аспекты работы программы (CLI, базовые сценарии, преобразования типов, синтаксические и семантические ошибки). Включает кроссплатформенные скрипты запуска (`run.bat` и `run.sh`).

\- `docs/` — программная документация, сгенерированная с помощью Doxygen.



\## Использование

Запуск программы осуществляется из командной строки со следующими аргументами:



```bash

countCyclesCPU <inputFile> \[weightFile] <outputFile>

```



\*\*Аргументы:\*\*

\- `inputFile` \*(обязательный)\* — файл с выражением в ОПЗ и объявлением типов переменных.

\- `weightFile` \*(опциональный)\* — файл с пользовательскими весами операций и правилами конвертации типов.

\- `outputFile` \*(обязательный)\* — файл для вывода инфиксной записи, DOT-графа и итоговой стоимости в тактах.



\*Примечание:\* Все ошибки (лексические, синтаксические, семантические, файловые) выводятся в стандартный поток ошибок (`stderr`) в консоль.



\## Сборка

Проект использует систему сборки qmake. Для компиляции откройте файл `countCyclesCPU.pro` в Qt Creator и запустите сборку, либо выполните в консоли:



```bash

qmake countCyclesCPU.pro

make

```



\## Тестирование

Для запуска автоматических тестов перейдите в директорию `tests/` и выполните скрипт, соответствующий вашей ОС:

\- \*\*Windows:\*\* Запустите `run\_bat.bat`
